# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use [GitHub's private vulnerability reporting](https://github.com/andmev/tahoe-wallpaper-switcher/security/advisories/new) for this repository. Include a clear description of the issue, steps to reproduce it, the affected version or commit, and any potential impact.

We will acknowledge reports within 7 days and aim to provide an assessment, fix, or mitigation as soon as practical. Please allow time for a fix before publicly disclosing the vulnerability.
